# Ride a Pet Wiki (`ride-a-pet-rblx.wiki`)

[![Site Status](https://img.shields.io/badge/Site-Live-brightgreen)](https://ride-a-pet-rblx.wiki/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An independent, fan-made interactive wiki and guide hub for the popular Roblox game **Ride a Pet**. This repository contains the source code, databases, and documentation for [ride-a-pet-rblx.wiki](https://ride-a-pet-rblx.wiki/).

---

## 📖 Overview

The goal of this wiki is to provide **Ride a Pet** players with accurate, accessible, and fast-loading information to help them optimize their gameplay loop: searching for eggs, hatching pets, upgrading movement speed, and executing rebirths.

### Key Features & Databases

- 🐶 **Pets Database**: Comprehensive guide covering pet stats, speed multipliers, and acquisition paths.
- 🥚 **Eggs & Spawn Map**: Complete list of eggs (e.g., Solaris, Cherub, Blackhole, Volcanic) with spawn timers and location guides.
- 🔄 **Rebirth System**: Requirements, sacrifice conditions, and permanent stat boosts for each rebirth tier.
- 🧪 **Mutations & Weather**: Interactive guides on mutation stacking, weather traits, and speed/earnings multipliers.
- ⚙️ **Gears & Radars**: Gear shop items and radar functionality breakdown for efficient egg farming.
- 🍖 **Food & Leveling**: EXP charts and food items to maximize pet income generation and movement speed.

## 🛠️ Tech Stack

## 🚀 Getting Started Locally

To run this wiki website locally on your machine for testing or contribution:

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm` or `pnpm` / `yarn`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/ride-a-pet-wiki.git
   cd ride-a-pet-wiki
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to view the site live.

## 🤝 Contributing

We welcome contributions from the community! Game updates happen frequently in Roblox, so keeping our data accurate is a team effort.

### How to Help

1. **Report Inaccuracies**: Notice outdated stats or broken links? Open an [Issue](https://github.com/your-username/ride-a-pet-wiki/issues).
2. **Submit Updates / Guides**:
   - Fork the repository.
   - Create a feature branch (`git checkout -b update/egg-spawns`).
   - Commit your changes with clear messages (`git commit -m "Add Volcanic Egg spawn coordinates"`).
   - Push to your branch and open a **Pull Request**.
